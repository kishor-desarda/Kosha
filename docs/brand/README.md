# Kosha brand

The Kosha logo is an orange treasury emblem with a lowercase *kosha* wordmark. Use the files here
rather than redrawing it; the name and logo follow the [trademark policy](../../TRADEMARKS.md).

## Files

| File | Use |
| --- | --- |
| `kosha-logo-primary.svg` | Horizontal logo for light backgrounds (charcoal wordmark) |
| `kosha-logo-dark.svg` | Horizontal logo for dark backgrounds (ivory wordmark) |
| `kosha-stacked-primary.svg` | Emblem above the wordmark, light backgrounds |
| `kosha-emblem.svg` | Emblem on its own (app icons, small spaces) |
| `github-social-preview-light.png`, `github-social-preview-dark.png` | Repository social preview, 1280 x 640 |
| `github-avatar-1024.png` | Avatar for the GitHub organisation or account |
| `open-graph.png` | Link preview image for web pages and posts |
| `Kosha_Brand_Guide.pdf` | The full brand guide |

The web client uses the same artwork from `web/brand/` (favicon, app icons, web app manifest and
the sign-in logo); the Office add-in and Kosha Desktop icons are made from it too.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Orange | `#EF5A28` | The emblem and small accents (`--brand` in `web/app.css`) |
| Charcoal | `#262522` | Wordmark and text on light backgrounds |
| Ivory | `#FAF8F4` | Light backgrounds, wordmark on dark backgrounds |

Orange is an accent: use charcoal for small text on ivory. The interface keeps its own blue accent
for buttons and links.

## Using the logo

- Keep the original proportions and clear space of at least a quarter of the emblem's height.
- Use the horizontal logo at 220 px wide or more, the emblem alone at 32 px or more.
- No shadows, gradients, outlines, other colours, stretching or rotation.
- The SVG files are the masters: the wordmark is outlined artwork, so no font is needed.
